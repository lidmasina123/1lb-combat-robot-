# Zagitis - 1lb Combat Robot

## Overview

**Zagitis** is my 1lb combat robot. Unlike most robots in this weight class, which usually use a fixed spinning weapon, Zagitis uses an **articulating weapon arm** with a spinning mass mounted on the end.

This allows the weapon to feed into the opponent more effectively, increasing the amount of damage it can deal. The robot is designed to attack the opponent's **top armor**, since this is usually one of the weakest parts of most combat robots.

I built this robot because many 1lb robots are very similar—they are usually 4-wheel-drive vertical eggbeaters. Building something that is only slightly better than everyone else's design is difficult and expensive, so instead I decided to build a robot that counters the common design by attacking their weak top plates.

# Key Features

### 1. Fully Brushless Drive
The drive system is completely brushless, giving a better power-to-weight ratio and improved efficiency.

### 2. Carbon Fiber + TPU Construction
The robot combines carbon fiber with TPU printed parts. This allows it to absorb impacts while remaining structurally rigid.

### 3. Compact Electronics
The robot uses **two Repeat Robotics dual drive ESCs**, allowing all of the electronics to fit into a very compact chassis.

### 4. Narrow but Wide Design
The robot is narrow from the front while maintaining a wide wheelbase. This reduces the number of exposed sides where opponents can gain an advantage.

### 5. 4S Battery
Most 1lb robots run on 3S batteries. Zagitis uses a **4S battery** for increased power.

### 6. Two Configurations
The robot has two different armor configurations:

- Configuration for vertical spinners
- Configuration for horizontal spinners
### 7. Tangent Drive

Unlike most 1 lb combat robots, which use smaller motors paired with gearboxes, Zagitis uses **tangent drive motors**. This allows for larger, more powerful motors while eliminating the gearbox, reducing complexity and improving efficiency.

# Weapon

The weapon consists of an articulating arm with a high-speed spinning mass mounted at the end.

Unlike a traditional fixed spinner, the arm can position the weapon above an opponent, allowing it to attack vulnerable top armor and feed the spinning weapon into the target for more effective hits.
